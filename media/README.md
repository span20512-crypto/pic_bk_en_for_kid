# media/ — 开发期本地素材（不进仓库）

本目录存放**版权受限的原版参考素材**（如小红书原视频），仅用于开发机本地效果比对。
整个目录已在 `.gitignore` 中排除（本 README 除外）——**这些素材不进小程序包、
不推 GitHub、不进正式环境**（PRD §2.2 内容政策）。

## 素材处理：剔除第三方叠加物

原片画面被三层第三方内容包裹：顶部小红书条与推广横幅、底部**烧录的中英字幕**与
引流条、以及画面内游走的 `@快乐学英语` 水印。前两者会与本产品自己的字幕重叠，必须去掉：

```bash
swift scripts/clean-media.swift \
  media/impatient-caterpillar.orig.mp4 media/impatient-caterpillar.mp4 \
  0.305 0.635 5.0 0.34 0.66 1400000
#              │     │     │    │    │    └ 码率
#              │     │     │    └────┴────── 模糊带：左止 34% / 右起 66%（羽化过渡）
#              │     │     └───────────────── 模糊强度 sigma
#              └─────┴─────────────────────── 保留区上下边界（占全高比例）
```

- **裁剪**：只保留全高 30.5%~63.5% 的纯动画区 → 720×422。顶部横幅、底部烧录字幕与
  引流条一并去除。边界是逐帧抽样量得的，换素材需重新量。
- **水印**：⚠️ **无法真正剔除**。它在画面左 6~32%、右 62~90% 之间游走且与主体重叠——
  裁剪要裁到只剩中间 36% 才能避开，不可行；自动定位不可靠（半透明白字特征太弱）；
  中值滤波保得住画面但消不掉。本机无 AI inpainting，现方案是对其出没的左右边缘带做
  羽化高斯模糊，使其**不可辨读**（代价：边缘背景变虚）。
- **音轨**原样转码保留 —— verbatim 模式要用原声朗读（PRD §2.2 例外条目）。

处理后画面是 1.7:1 宽幅，阅读器对本地素材用 `objectFit: contain` 完整显示，
上下留白填深色（`.stage-local`）。

> ⚠️ **换素材后必须把 `src/utils/config.ts` 的 `LOCAL_MEDIA_VERSION` +1**。
> URL 不变时微信会沿用已缓存的旧视频 —— 曾因此在真机上看到"处理没生效"（画面仍带
> 原片横幅与字幕），而服务端其实早已是新文件。改版本号会让 URL 变化，强制重新拉取。

## 用法

1. 素材放进本目录，文件名与 `src/data/books/` 里对应书的 `local.file` 一致
2. 启动本地媒体服务器：`npm run serve:media`（本机已注册 launchd 常驻，通常无需手动跑）
3. 小程序启动时探活，成功则阅读器按每页 `local.clip` 分段播放，失败回落 Mixkit 占位
4. 真机：手机与电脑同一 Wi-Fi 即可，客户端会自动命中 `LOCAL_MEDIA_BASES` 里的局域网 IP
